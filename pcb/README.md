# Macropad main PCB: Altium inputs

One folder per concept (`A/`, `B/`, `C/`), generated by `generate.py` from the case model, so the board always matches the printed case. B is the one to start with.

| File | What it is |
|---|---|
| `BOM.csv` | Every part with a UK price estimate. The last two rows (screen, LiPo) are off-board. |
| `connections.csv` | Net, designator, pin. Easiest way to check a connection by eye. |
| `macropad_<c>.NET` | Protel netlist. In Altium: create the PCB, then **Design > Import Changes From** / **Import Netlist**. |
| `placement.csv` | Position, side and rotation of every part, in mm. |
| `placement.svg` | The same as a drawing (top view, bottom-side parts seen through the board). |
| `pcb_outline.dxf` | Board outline with the MX centre holes, M2 pillar holes and the display opening. |

All coordinates use the case's frame: origin at the case's front-left corner, x to the right, y toward the back (the screen end). Import the DXF on a mechanical layer with that origin (**Edit > Origin > Set** on the DXF's 0,0) and the placement numbers line up.

Rebuild after changing the case, from the repo root: `python tools/build.py` then `python pcb/generate.py` (needs `pip install shapely`).

## Controller pin map

The controller is a SuperMini nRF52840 (chosen 2026-10-21), a clone of the nice!nano v2; a genuine nice!nano is a drop-in swap. Same table as `firmware/boards/promicro_nrf52840_nrf52840_uf2.overlay`.

Things that drove this map:

- **Nordic marks 21 pins "low frequency I/O only"** (keep them under about 10 kHz). On a Pro Micro footprint that is pins 11-20 (P1.04, P1.06, P0.09, P0.10, P1.11, P1.13, P1.15, P0.02, P0.29, P0.31). The 16 MHz LCD clock and data therefore sit on P0.17 and P0.20; the key matrix, knob, reset and backlight PWM are slow and can use the restricted pins.
- **P0.09 / P0.10 are the NFC antenna pins.** The board file already frees them as GPIO. They leak a little current between each other when held at different levels, so they carry the knob: both contacts are open (pulled high) at every detent.
- **The VCC pin is off until firmware drives P0.13 high** on SuperMini boards (it enables the regulator behind VCC). The firmware does this through a `regulator-fixed` node, so the LCD gets power before the display driver starts.

## Matrix

Rows are inputs with pull-ups, columns are driven low one at a time (Zephyr's `gpio-kbd-matrix`). Each switch goes from its row to a 1N4148W anode; the cathode goes to the column. Matrix row 0 is the back row, next to the screen; `SW1` is the back-left key, which is key 0 in the firmware and the top-left tile on screen. The knob's push switch is wired into row 0 in its own column (with its own diode), and the firmware calls it key 16 on every concept.

| Concept | Rows x columns | Knob push |
|---|---|---|
| A | 3 x 4 | row 0, COL3 |
| B | 3 x 5 | row 0, COL4 |
| C | 4 x 5 | row 0, COL4 |

## Assembly notes

- **U1 goes on the bottom layer, components facing down,** on 2.5 mm low-profile headers. Placing the standard Pro Micro footprint on the bottom layer in Altium mirrors it correctly. Keep the USB-C end toward the back wall (+y); the case has a 13 x 7.5 mm opening there.
- **On B and C the knob sits right above U1.** Trim the EC11's pins and mounting lugs flush under the board before fitting U1, and put a piece of Kapton tape on U1's back.
- **The space between the PCB top and the case skin is 2 mm.** Header pins and anything else poking up through the board must be trimmed flush.
- **LCD:** the Waveshare modules come with an 8-wire PH2.0 cable. Cut the far end and solder the wires into J2 in the module's order (VCC, GND, DIN, CLK, CS, DC, RST, BL). Leave enough slack to lift the module out of the window.
- **Power switch:** a right-angle SPDT slide switch on the bottom side, actuator out of the slot in the right wall. The part and its height are a best guess; check the actuator reaches through the 2.4 mm wall before ordering boards.
- **Reset button:** only needed if a firmware update goes wrong (double-press = UF2 bootloader). The firmware has a combo for normal updates: hold the top-left key and press the knob for 3 seconds.
- **SuperMini extras:** the three pins in the middle at the far end from USB (P1.01, P1.02, P1.07) are not used and need no header. The four SWD pads on its back (VDD, SWDIO, SWCLK, GND) are the way back in if the UF2 bootloader is ever damaged: the DK's Debug out header can reprogram it.
- **Charging speed:** the SuperMini charges at 100 mA, about 9 hours for a flat 800 mAh LiPo. Bridging the BOOST jumper on its back raises that to 300 mA (about 3 hours), which is fine for this cell but not for one under 500 mAh.
- **Placement check:** `generate.py` refuses to write files if two bottom-side parts overlap, a part leaves the board, or a part lands in the display opening. U1 under the knob is the one allowed overlap.
